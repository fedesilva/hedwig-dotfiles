# Repository instructions

- This repository contains personal dotfiles. Keep changes small and focused.
- Read the relevant configuration before editing and preserve existing conventions.
- Use Git Town for branch and pull request workflows. Follow `git-town.toml`; the main branch is `master`.
- Preserve unrelated local changes.
- Validate changed configuration with the relevant tools when available.
- Keep durable documentation self-contained or link to versioned repository files, never temporary or machine-local evidence.
